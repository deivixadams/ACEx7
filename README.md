# ACEx7 - Audit Corpus Engine x7

## Overview
ACEx7 is a high-performance, premium AML (Anti-Money Laundering) and CFT (Counter-Financing of Terrorism) Audit Management System. Designed for the Dominican Republic jurisdiction, it provides a traceable, automated, and visually advanced framework for managing compliance requirements, risks, and controls.

## Key Features
- **Premium Dashboard**: Neon Lime interface with advanced glassmorphism and real-time data visualization using `recharts`.
- **Traceable AML Framework**: Full mapping of regulatory requirements to operational risks and mitigation controls.
- **Project Management**: Automated tracking of audit findings, timelines, and auditor performance.
- **Multilingual Support**: Built-in support for multiple locales (English/Spanish).

## Tech Stack
- **Frontend**: Next.js 16 (App Router), Tailwind CSS, Lucide React.
- **Visualization**: Recharts.
- **Backend**: Node.js, Prisma ORM.
- **Database**: PostgreSQL / SQLite (Development).

## Getting Started

### Prerequisites
- Node.js 18+
- PostgreSQL instance

### Installation
1. Clone the repository.
2. Navigate to the `dashboard` directory:
   ```bash
   cd dashboard
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Set up your environment variables in `.env`.
5. Run the development server:
   ```bash
   npm run dev
   ```

## Repository Structure
- `dashboard/`: The main Next.js application.
- `prisma/`: Database schema and migrations.
- `docs/`: Technical and regulatory documentation.
